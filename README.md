**Koishi** 是一款面向 Windows 用户的 AI 桌面伴侣软件。

她不仅可以陪伴在你的电脑桌面上，还可以通过连接大语言模型，实现自然语言交流，并结合知识库、记忆和可选工具功能，为你的日常电脑使用提供帮助。

## ✨ 主要功能

### 🐝 桌面宠物陪伴

* 桌面宠物展示与交互
* 支持调整桌宠大小
* 保留用户的部分个性化设置

### 💬 AI 智能交流

* 支持用户自行配置兼容的大语言模型 API
* 通过自然语言与 Koishi 交流
* 未配置 API 时，部分 AI 功能无法使用

### 📚 知识库与记忆

* 提供知识库与记忆相关功能
* 支持保存和管理部分用户数据

### 🌐 联网搜索

* 支持配置独立的联网搜索 API
* 根据模型及工具配置使用联网搜索功能

### 🛡️ 工具和终端权限

* 支持可选的 AI 工具调用
* AI 终端权限默认关闭
* 用户需要主动授权才能启用相应能力
* 可通过相关设置关闭权限

## 🚀 安装与使用

1. 下载 `Koishi_Setup_1.7.0.exe`。
2. 按照安装向导完成安装。
3. 启动 Koishi。
4. 根据需要调整桌宠外观和大小。
5. 如需使用 AI 功能，请自行配置大模型 API。
6. 如需使用联网搜索，请配置相应的搜索 API。
7. 终端和工具权限请根据个人需要谨慎开启。

详细使用方法请参考发行页面中的软件说明书和安装指南。

## 🔒 安全与隐私

我们重视用户的使用安全和隐私。

* 安装包不预置开发者的私人 API Key。
* 用户需要自行配置第三方 API。
* AI 终端权限采用默认关闭的设计。
* 部分用户设置和数据保存在本地。
* 第三方模型及搜索服务的数据处理规则以对应服务商的隐私政策为准。

请勿向他人泄露自己的 API Key。
